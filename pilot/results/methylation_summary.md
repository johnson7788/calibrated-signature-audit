# 跨组学验证：DNA 甲基化（GSE48684）

> 目的：验证审计引擎能否迁移到转录组之外的数据类型（表观组）。
> 数据：GSE48684（Illumina 450K，GPL13534），beta 值矩阵
> 日期：2026-11-27

## 1. 数据与处理

| 项 | 值 |
|---|---|
| 样本 | 147：CRC 64 / 癌旁正常 24 / 腺瘤 42 / 健康正常 17 |
| 特征 | 485,578 个 CpG 探针 |
| 原始文件 | series matrix 296MB（GEO FTP） |
| 缺失 | 94,659 格（0.13%），按行中位数填补 |
| 检验 | 非配对 Welch t 检验 + BH 校正（alpha=0.05，|效应|≥0.1） |

## 2. 结果

| 对比 | 差异位点数（FDR<0.05 且 |Δbeta|≥0.1） | 最小 p |
|---|---|---|
| CRC vs 癌旁正常 | **78,552** | 2.5e-36 |
| 腺瘤 vs 健康正常 | **116,917** | 3.9e-31 |

## 3. 解读

**① 引擎可迁移**：同一套"矩阵 + 元数据 + 检验 + 分级判定"的流程，无需改代码即可吃下 450K 甲基化数据（485k 特征、非配对、beta 尺度）。这验证了方法论的组学无关性。

**② 但"可迁移"不等于"结论可直接类比"**：
- beta 值是 0–1 的甲基化比例，效应 0.1 = 10 个百分点差异，与转录组的 log2FC 不可直接比较；
- 探针级差异 ≠ 基因级结论：需要 probe→gene 映射（GPL13534 注释体积大，本轮未做）；
- 探针高度相关（同 CpG 岛），FDR 校正假设独立性，**差异位点数会严重高估独立信号数**——这正是"计数不能当结论"的又一例证。

**③ scan 是探索不是审计**：本轮没有"论文声称"作为对照，只能回答"数据里有没有系统差异"，不能回答"某篇论文的结论是否复现"。若要做甲基化审计，需要：论文声称的差异甲基化基因列表 + probe→gene 映射 + 方向预期（如高甲基化对应低表达）。

## 4. 局限

1. 未做 probe→gene 聚合，结论停留在探针层；
2. 未做配对（GSE48684 的 CRC/癌旁样本未提供明确配对编号）；
3. 甲基化与表达的方向关系（负相关）未验证——这是连接转录组审计的下一步；
4. 平台/批次差异未建模。

## 5. 下一步（连接回转录组）

1. **probe→gene 映射**：用 GPL13534 注释把 78,552 个差异探针聚合到基因，与 GSE50760 的上下调签名做**方向一致性检验**（高甲基化基因是否低表达）；
2. **配对化**：寻找带配对设计的甲基化队列（如 GSE131013 的 paired normal/tumor 标题格式）；
3. **跨组学签名**：把"表达下调 + 启动子高甲基化"作为复合签名，在独立队列检验。
